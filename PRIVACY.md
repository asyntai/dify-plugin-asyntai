# Privacy Policy

## Data Collection

The plugin asks for one credential: an Asyntai API key. Dify stores it in the
workspace credential store. The plugin does not keep its own copy.

When a tool runs, the plugin sends to the Asyntai API only the values of that
tool call: a question, a URL, a title and a text, a session ID, a website ID, or
a search filter such as an email address or a date.

Two tools return personal data that already belongs to the Asyntai account: the
email addresses and phone numbers visitors left in the website chat, and the
messages of those chats.

## Data Usage

The plugin calls one third-party service, Asyntai, at `https://asyntai.com`.
Asyntai answers the question, stores the knowledge base item, or returns the
chats and leads of the account the API key belongs to. See the
[Asyntai privacy policy](https://asyntai.com/privacy-policy/).

The plugin sends data to no other service.

## Data Retention

The plugin stores nothing. Each tool call ends when its answer is returned.

Knowledge base items, chats and leads live in the Asyntai account. The account
owner can delete any of them in the Asyntai dashboard, or through the Asyntai
API.

## Contact

Write to hello@asyntai.com for any question about this plugin and privacy.
